# Gaming Web App Voice and Tone

Use this guide for game-server hosting, control panels, dashboards, community tools, and technical gaming products.

## Voice pillars

### Clear and direct
Say what happened, what state the system is in, and what the user can do.

**Do**
- Server restarted
- Update available
- Backup failed
- Join Discord

**Don't**
- Your requested operation has been completed successfully
- An issue has occurred while processing your request

### Confident and calm
Operational software should feel dependable even when something is wrong.

**Do**
- Server controls are temporarily unavailable.
- Connection lost. Reconnect to continue.

**Don't**
- Critical disaster!
- We sincerely apologize for this unfortunate inconvenience.

### Helpful
Give the next useful action when there is one.

**Do**
- Server failed to start. Check the console for the latest error.
- No servers found. Clear your filters or create a new server.

**Don't**
- Failed.
- No results.

### Technical when needed
Keep domain terms users need for operation and troubleshooting.

Prefer accurate terms such as:
- RCON
- Query port
- Console
- Node
- Backup
- Mod
- Plugin
- DDoS protection

Explain technical terms only when the audience may not know them.

### Gaming-friendly, not gamer-slang heavy
Use modern, familiar language without forcing jokes or hype.

**Good**
- Ready to play
- Server is online
- Invite your squad

**Avoid by default**
- GG EZ
- Let's frag
- Epic server unlocked
- Bro, your server died

Use playful language only in clearly low-stakes moments such as optional achievements or community campaigns.

## Tone by situation

### Routine control
Tone: fast, neutral, efficient.

Examples:
- Start server
- Restarting
- Changes saved

### Failure
Tone: calm, factual, recovery-focused.

Examples:
- Backup failed. There isn't enough storage available.
- Server stopped unexpectedly. Check the console for details.

### Destructive action
Tone: serious, explicit, non-dramatic.

Examples:
- Delete this backup?
- Wipe server data?
- Cancel subscription?

Do not soften consequences so much that risk becomes unclear.

### Maintenance
Tone: operational and factual.

Example:
- Server controls are temporarily unavailable during maintenance. Running servers are not affected.

### Billing
Tone: neutral and precise.

Example:
- Payment failed. Update your payment method to keep the service active.

Avoid shame, urgency tricks, or manipulative countdown language.

### Community features
Tone: friendly and inclusive.

Examples:
- Join the community
- Ask for help on Discord
- View server rules

### Enforcement and moderation
Tone: neutral and factual.

Examples:
- Banned for 7 days
- Appeal available until 14 Oct
- Access revoked

Do not joke about bans, punishment, appeals, or account restrictions.

## Voice anti-patterns

Avoid:
- Corporate filler
- Excessive politeness in routine UI
- Forced gaming slang
- Vague technical language
- Fake empathy
- Over-celebration for trivial actions
- Writing that sounds translated
- Marketing language inside operational controls
